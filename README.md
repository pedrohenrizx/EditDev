# Edit.Dev

Edit.Dev é uma plataforma de livraria online dedicada à venda de eBooks por meio de planos de assinatura. O projeto oferece uma experiência rica para os usuários, permitindo um acesso fácil a uma vasta biblioteca de conteúdos literários.

## Funcionalidades

- **Assinaturas**: Dois planos de assinatura disponíveis: Básico (grátis) e Pro (R$5,00/mês).
  - [Plano Básico]: Até 2 downloads por mês, acesso aos 3 primeiros capítulos de cada livro, e contato restrito.
  - [Plano Pro]: Acesso total aos livros, downloads ilimitados por mês, e contato sem restrições.

- **Sistema de Login e Cadastro**: Permite que os usuários criem contas e façam login para acessar os conteúdos.

- **Recuperação de Senha**: Funcionalidade para recuperação de senhas esquecidas.

- **Perfis Personalizáveis**: Usuários podem personalizar suas biografias e fotos de perfil.

- **Sistema de Favoritos**: Usuários podem salvar eBooks favoritos para fácil acesso.

- **Notificações**: Receba notificações sobre novos eBooks e promoções.

- **Integração com Redes Sociais**: Permite o compartilhamento de eBooks nas plataformas sociais.

- **Blog**: Seção para artigos sobre literatura, resenhas e dicas.

- **Feedback dos Usuários**: Sistema para coletar opiniões e sugestões dos usuários.

- **Analytics**: Monitoramento do tráfego e engajamento dos usuários.

- **Suporte Multilíngue**: Ampla acessibilidade com suporte a múltiplos idiomas.

- **Funcionalidade Offline**: Os usuários podem baixar eBooks para leitura offline.

## Tecnologias Utilizadas

- `HTML` e `Tailwind CSS` para estilização e design responsivo.
- `JavaScript` para interatividade e funcionalidades dinâmicas.
- `Node.js` como ambiente de servidor.
- `SQLite` para gerenciamento de dados e armazenamento.

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone <URL_do_repositório>
   cd Edit.Dev
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor:
   ```bash
   node server.js
   ```
4. Abra o navegador e acesse `http://localhost:3000`
